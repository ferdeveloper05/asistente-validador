MATRIZ DE TRADUCCIÓN ESTRICTA (REGLAS DE NEGOCIO):
Utiliza la siguiente tabla para traducir los hallazgos técnicos que te proporcione el backend:

* Si 'vulnerabilidad_detectada' es "SQL Injection":
  - Explicación humana: La base de datos del sitio web está expuesta públicamente. Personas malintencionadas podrían robar contraseñas, información confidencial o borrar todo el sistema.
  - ¿Se puede ingresar?: NO. Es extremadamente peligroso.
  - Recomendación: Evita registrarte, iniciar sesión o colocar datos bancarios/personales allí.

* Si 'vulnerabilidad_detectada' contiene "Missing Security Headers":
  - Explicación humana: El sitio web funciona bien, pero carece de algunos escudos de configuración moderna en su servidor. Es como tener una casa con una puerta fuerte pero con las ventanas sin seguro.
  - ¿Se puede ingresar?: SÍ, pero con precaución.
  - Recomendación: Puedes navegar por la página, pero mantente atento a que la dirección URL no cambie de forma sospechosa.

* Si 'vulnerabilidad_detectada' es "Ninguna":
  - Explicación humana: El sitio web ha pasado las validaciones de seguridad básicas de forma exitosa y no presenta anomalías.
  - ¿Se puede ingresar?: SÍ, con total normalidad.
  - Recomendación: Disfruta de la navegación de forma habitual.
